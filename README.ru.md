# FH2-LivingCockpit

**Живой кокпит для Forza Horizon 2 (Xbox One) на эмуляторе Azimuth (0.9.9; 0.9.5–0.9.7 тоже).** В виде из кабины голова водителя
реагирует на машину — смотрит в поворот, наклоняется от перегрузок, ныряет при торможении, смотрит туда, куда едет
машина в заносе, кивает при переключении передач, качается на неровностях, — и чувствуется скорость: обзор
раскрывается, края темнеют, поток воздуха трясёт картинку, газ распахивает обзор. И переключатель родного размытия в
движении. Одна DLL, оба переключателя — в настройках самой игры.

## Что делает
**Кокпит** (остальные виды остаются родными)
| | |
|---|---|
| **Смотрит в поворот** | Голова плавно поворачивается в сторону поворота (14° в крутом повороте), с мёртвой зоной для мелкого подруливания. |
| **Наклоняется** | Горизонт кренится, голову относит к внешней стороне поворота. |
| **Занос** | В заносе голова смотрит туда, куда едет машина. |
| **Торможение и разгон** | Глубже нырок вперёд при торможении и вжатие назад при разгоне. |
| **Передачи** | Короткий кивок от толчка. |
| **Неровности и поребрики** | Неровности под каждым колесом ощущаются сильнее. |
| **Поле зрения** | 65° вместо родных 48°. |

**Скорость** (в кокпите, с 90 км/ч, полностью к 260 км/ч)
| | |
|---|---|
| **Шире обзор** | Поле зрения расширяется на 12° на полной скорости — мягко, «дышит» вместе со скоростью. |
| **Тяга** | На полном газу обзор раскрывается ещё на 5°, при резком торможении сужается на 3°; при переключении передач тяга на миг пропадает, и обзор «бьёт». |
| **Затемнение краёв** | Виньетка, сжимающаяся на большой скорости. |
| **Ветер** | Мелкая дрожь от потока воздуха на большой скорости. |

**В настройках игры** (*Настройки > HUD*, сразу после пункта камеры; с названиями и описаниями на всех языках игры;
срабатывают сразу и сохраняются)
| | |
|---|---|
| **Живая камера** | Всё перечисленное выше вкл/выкл. Выключено — кокпит ровно как в игре. |
| **Размытие в движении** | Родное размытие игры во всех видах — кокпит, капот, бампер, сзади, зеркало, повторы и ролики — вкл/выкл. В фоторежиме остаётся своя выдержка. |

## Что нужно
- Forza Horizon 2 для Xbox One (1.0.0.64) на **Azimuth 0.9.9** (0.9.5–0.9.7 тоже подходят). Не входят; нужна своя
  копия.
- Загрузчик модов из релиза (`azimuth-tls.dll`, тот же, что в [FH2-DualSense](https://github.com/alezwork/FH2-Dualsense))
  или любой загрузчик, который грузит `mods\*.dll` после того, как игра загружена в память. Работает вместе с
  [ExtraOptions](https://github.com/RokkuDayo/ForzaHorizon2_ExtraOptions).

## Установка
1. Скачайте `LivingCockpit.dll` (и `azimuth-tls.dll`, если загрузчика модов ещё нет) из [Releases](../../releases).
2. **Загрузчик модов** (один раз): в `<Azimuth>\data\bin\` переименуйте лежащий там `azimuth-tls.dll` (родной от
   Azimuth или от ExtraOptions) в `azimuth-tls.dll.original` и положите туда скачанный `azimuth-tls.dll`. Загрузчик
   сначала грузит `azimuth-tls.dll.original`, потом моды, так что ExtraOptions работает как раньше. При обновлении
   ExtraOptions его новый `azimuth-tls.dll` кладётся как `azimuth-tls.dll.original`.
3. Положите `LivingCockpit.dll` в `<Azimuth>\mods\` (создайте папку, если её нет).
4. Запустите игру. `LivingCockpit.ini` появится в `mods\` при первом запуске; лог — `mods\LivingCockpit.log`.

Работает вместе с [FH2-DualSense](https://github.com/alezwork/FH2-Dualsense): оба при запуске меняют часть одних и
тех же файлов игры (экраны настроек, таблицы строк, список архивов), и каждый сохраняет правки другого. С
[ExtraOptions](https://github.com/RokkuDayo/ForzaHorizon2_ExtraOptions) его пункты меню тоже остаются, а поле зрения
кокпита задаёт его ползунок *FOV - Водитель* (`[Camera] FieldOfView` тогда не используется); скорость и тяга всё так же
расширяют обзор поверх. Если у него включена камера дрифта для вида водителя, `SlideLook=0` убережёт от двойного
взгляда в занос.

**Удаление**: удалите `LivingCockpit.dll` (и `LivingCockpit.ini`, `LivingCockpit.log`, `LivingCockpit.cache\`) из
`mods\`.

## Настройки (`mods\LivingCockpit.ini`)
| `[Camera]` | |
|---|---|
| `Enabled` | 1 вкл, 0 выкл — то же, что *Живая камера* в игре. |
| `MotionBlur` | 1 родное размытие, 0 без размытия — то же, что *Размытие в движении* в игре. |
| `FieldOfView` | Поле зрения кокпита, градусы (у игры 48; 0 — как в игре). С ExtraOptions — вместо него его ползунок *FOV - Водитель*. |
| `LookIntoTurns` | Градусы в крутом повороте. Если голова смотрит из поворота — сделайте отрицательным. |
| `TurnDeadzone` | Процент крутого поворота, ниже которого голова смотрит прямо. |
| `Lean` | Крен и смещение наружу, в процентах. |
| `Pitch` | Насколько нырок и вжатие глубже родных, в процентах (0 — как в игре). |
| `Bumps` | Неровности и поребрики, в процентах от родных. |
| `Shake` | Лёгкая дрожь, растущая со скоростью, в процентах (0 — нет). |
| `SlideLook` | На сколько градусов голова поворачивается в заносе туда, куда едет машина (отрицательное — в другую сторону). |
| `GearKick` | Кивок при переключении передач, в процентах (0 — нет). |

| `[Speed]` | |
|---|---|
| `From`, `Full` | Скорость, с которой эффекты начинаются, и скорость, на которой они полные, км/ч. |
| `FieldOfView` | На сколько градусов шире обзор на полной скорости (0 — нет). |
| `Vignette` | Затемнение краёв на полной скорости, в процентах (0 — нет). |
| `WindShake` | Дрожь от потока воздуха, в процентах (0 — нет). |
| `Thrust` | Раскрытие обзора на газу (5° при 100) и сужение при торможении (3°), в процентах (0 — нет). |

Силы эффектов читаются при запуске игры; оба переключателя работают сразу.

## Как это устроено
- **Камера.** Игра двигает камеры по данным, `media\Camera.zip\CameraPhysics.xml`: у каждой камеры список слоёв,
  каждый берёт вход (перегрузки, проскальзывание, удары, неровности под колёсами, скорость...) и через кривую, шум и
  пружину меняет положение, поворот, поле зрения, виньетку камеры... Камера водителя почти не реагирует на повороты:
  её слои боковых перегрузок выключены. При запуске игры LivingCockpit собирает `Camera.zip` заново с 27 слоями после
  родных слоёв кокпита (родные не трогаются), в обоих файлах — с эффектами и без, ставит поле зрения в
  `CameraSettings.ini` и отдаёт новый архив игре вместо оригинала (перехвачены файловые вызовы движка; в
  `zipmanifest.xml` — новый каталог архива). Виньетка — родная виньетка камеры, та же, что в фоторежиме.
- **Переключатель.** Игра читает списки слоёв всех камер через одну функцию (FH2 1.0.0.64: `0x103AA00`, находится по
  `NumLayers`); она перехвачена, чтобы запомнить, где в памяти списки кокпита, — так *Живая камера* сразу включает и
  выключает мои слои. Переключатели — новые свойства модели экрана настроек HUD по образцу родной настройки камеры и
  строки в `A_HUDOptions.xaml`. Их названия и описания — ключи (`IDS_HudOption_LivingCamera`,
  `IDS_HudOption_MotionBlur` и их `_Desc`), добавленные в `InGame.str` таблицы строк каждого языка
  (`media\stripped\stringtables\<LANG>.zip`, LSB2), так что игра показывает их на своём языке.
- **Размытие.** Класс камеры каждого вида отдаёт рендеру силу размытия через один виртуальный метод (у кокпита и камер
  сзади 1.0, у капота 0.6). LivingCockpit находит классы по RTTI и ставит в их vtable метод, который отдаёт родное
  значение или 0, когда *Размытие в движении* выключено.

Всё находится по сигнатурам кода, RTTI и содержимому файлов; если что-то не так, это пишется в лог и эта часть
остаётся родной.

## Сборка
```
set FH2_GAME=D:\Forza Horizon 2 XboxOne     папка с Azimuth\ (по умолчанию — на уровень выше)
build.cmd            собирает out\mods\LivingCockpit.dll
build.cmd install    и копирует её в %FH2_GAME%\Azimuth\mods
```
Загрузчик модов собирается в [FH2-DualSense](https://github.com/alezwork/FH2-Dualsense) (`loader\`).
Visual Studio Build Tools (C++) или zig (`python -m pip install ziglang`); Python 3 для `tools\ini2h.py`.
