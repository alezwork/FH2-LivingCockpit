# FH2-CockpitCam

**Живая камера в кокпите для Forza Horizon 2 (Xbox One) на эмуляторе Azimuth 0.9.7.** Голова водителя реагирует на
машину: смотрит в поворот, наклоняется от перегрузок, ныряет при торможении, смотрит туда, куда едет машина в заносе,
кивает при переключении передач, качается на неровностях, а на скорости обзор становится шире. Одна DLL, включается и
выключается в настройках самой игры.

## Что делает
| | |
|---|---|
| **Смотрит в поворот** | Голова плавно поворачивается в сторону поворота (14° в крутом повороте), с мёртвой зоной для мелкого подруливания. |
| **Наклоняется** | Горизонт кренится, голову относит к внешней стороне поворота. |
| **Занос** | В заносе голова смотрит туда, куда едет машина. |
| **Торможение и разгон** | Глубже нырок вперёд при торможении и вжатие назад при разгоне. |
| **Передачи** | Короткий кивок от толчка. |
| **Неровности и поребрики** | Неровности под каждым колесом ощущаются сильнее. |
| **Скорость** | Лёгкая дрожь и расширение обзора со скоростью. |
| **Поле зрения** | 65° вместо родных 48°. |

**Включение в игре**: *Настройки > HUD > Живая камера* (сразу после пункта камеры). Срабатывает сразу и
сохраняется в `CockpitCam.ini`.

## Что нужно
- Forza Horizon 2 для Xbox One (1.0.0.64) на **Azimuth 0.9.7** (не входят; нужна своя копия).
- Загрузчик модов, который грузит `Azimuth\mods\*.dll`: `azimuth-tls.dll` из
  [релиза FH2-DualSense](https://github.com/alezwork/FH2-Dualsense/releases) или любой другой.

## Установка
1. Скачайте `CockpitCam.dll` из [Releases](../../releases) и положите в `<Azimuth>\mods\`.
2. Запустите игру. `CockpitCam.ini` появится в `mods\` при первом запуске; лог — `mods\CockpitCam.log`.

Работает вместе с [FH2-DualSense](https://github.com/alezwork/FH2-Dualsense): оба при запуске меняют часть одних и
тех же файлов игры (экраны настроек, список архивов), и каждый сохраняет правки другого.

## Настройки (`mods\CockpitCam.ini`)
| `[Camera]` | |
|---|---|
| `Enabled` | 1 вкл, 0 выкл (то же, что переключатель в игре). |
| `FieldOfView` | Градусы; больше — шире и дальше обзор (у игры 48; 0 — как в игре). |
| `LookIntoTurns` | Градусы в крутом повороте. Если голова смотрит из поворота — сделайте отрицательным. |
| `TurnDeadzone` | Процент крутого поворота, ниже которого голова смотрит прямо. |
| `Lean` | Крен и смещение наружу, в процентах. |
| `Pitch` | Насколько нырок и вжатие глубже родных, в процентах (0 — как в игре). |
| `Bumps` | Неровности и поребрики, в процентах от родных. |
| `Shake` | Дрожь на скорости, в процентах (0 — нет). |
| `SlideLook` | На сколько градусов голова поворачивается в заносе туда, куда едет машина (отрицательное — в другую сторону). |
| `SpeedFieldOfView` | На сколько градусов расширяется обзор на скорости. |
| `GearKick` | Кивок при переключении передач, в процентах. |

Силы эффектов читаются при запуске игры; переключатель вкл/выкл работает сразу.

## Как это устроено
Игра двигает камеры по данным, `media\Camera.zip\CameraPhysics.xml`: у каждой камеры список слоёв, каждый берёт
вход (перегрузки, проскальзывание, удары, неровности под колёсами, скорость, приземления, слежение за головой...) и
через кривую, шум и пружину смещает или поворачивает камеру. Камера водителя почти не реагирует на повороты: её слои боковых
перегрузок выключены. При запуске игры CockpitCam собирает `Camera.zip` заново с 22 слоями после родных (родные не
трогаются), в обоих файлах — с эффектами и без, и ставит поле зрения кокпита в `CameraSettings.ini`; новый архив отдаётся игре вместо оригинала (перехвачены файловые вызовы движка; в `zipmanifest.xml` — новый каталог архива).

Игра читает списки слоёв всех камер через одну функцию (FH2 1.0.0.64: `0x103AA00`, находится по `NumLayers`); она
перехвачена, чтобы запомнить, где в памяти списки камеры водителя, — так переключатель сразу включает и выключает мои
слои (`Enabled` по +0x40, `Param` по +0xE0 каждого слоя в 0x110 байт). Сам переключатель — новое свойство модели
экрана настроек HUD по образцу родной настройки камеры и строка в `A_HUDOptions.xaml`. Всё находится по сигнатурам
кода; если что-то не так, это пишется в лог и камера остаётся родной.

## Сборка
```
build.cmd            собирает out\mods\CockpitCam.dll
build.cmd install    и копирует её в ..\Azimuth\mods и ..\Azimuth FF\mods
```
Visual Studio Build Tools (C++) или zig (`python -m pip install ziglang`); Python 3 для `tools\ini2h.py`.
